# Исправление ядра на 32-битном MT7621

Для ASUS RT-AX53U и других `ramips/mt7621` с `sing-box-tiny` 1.13.21 подготовлен
пакет `1.13.21-r100`, бинарник сообщает `1.13.21-obhod.1`. Это отдельное обновление
сетевого ядра; версия самого Обхода не меняется. Полное ядро с WireGuard не заменяется.

В sing-tun v0.8.15 случайный `uint32` преобразуется в платформенный `int` без
ограничения старшего бита. На 32-битной системе примерно половина значений становится
отрицательной. netlink добавляет атрибут отдельной таблицы только при `Table > 0`,
поэтому маршруты loopback могут попасть в `main`. Характерные признаки:
`append redirect route ... 127.0.0.1/32 ... Table: -...: file exists` и
`local 127.0.0.1 dev wan/br-lan/wg0` в таблице `main`.

Изменена одна строка: `int(rand.Uint32())` → `int(rand.Uint32() & 0x7fffffff)`.
Ограничение до 31 бита также используется в актуальной ветке upstream:
[sing-tun](https://github.com/SagerNet/sing-tun/blob/dev/redirect_route_linux.go).
Исправленный код основан на [sing-box v1.13.21](https://github.com/SagerNet/sing-box/tree/628cb31ffa79cffffd34c2f9cde6cae044e4fc12)
и [sing-tun v0.8.15](https://github.com/SagerNet/sing-tun/tree/f3b42b8b8e061ef849213a776d9fcf3d5f6ea239).

## Установка

Публичный установщик `openwrt/install-mips-core-fix.sh` проверяет целевой профиль,
наличие облегчённого ядра, свободное место в `/tmp`, размер и SHA-256 пакета.
Сохраняет настройки в закрытый архив `/root/obhod-before-mips-fix-*.tar.gz`,
останавливает Обход, устанавливает APK и удаляет скачанный пакет до запуска ядра,
чтобы освободить ОЗУ. Штатная отдельная служба sing-box должна быть остановлена;
её конфигурация сохраняется, запуском ядра управляет Обход.

Очистка касается только маршрутов типа `local` для `127.0.0.1/32` в таблице `main`.
Таблица `local`, правила маршрутизации и адреса/маршруты WireGuard не очищаются.
Если профиль Обхода существует, служба запускается после установки. Скрипт не
меняет прошивку и не устанавливает дополнительные протоколы.

APK предназначен для OpenWrt 25.12 с `apk`, IPK — для ручной установки на совместимых
прошивках с `opkg`. Если позже заменить это ядро обычным пакетом 1.13.21-r1 из
репозитория, ошибка может вернуться. Исправление полного ядра в этот пакет не входит.

## Сборка и проверка

Бинарник собран Go 1.26.8, `GOOS=linux GOARCH=mipsle GOMIPS=softfloat CGO_ENABLED=0`.
Теги: `with_gvisor,with_quic,with_utls,with_clash_api`; состав прокси-функций соответствует
облегчённому ядру. Пакет сохраняет служебные файлы и зависимости штатного OpenWrt APK.
Исходный APK получен через подписанный индекс OpenWrt 25.12.6; SHA-256:
`6323a0aa122f0b9556a256c9b4f85176ec42ce947bda7c9fa4294711023edd39`.

Рядом с пакетами публикуется архив соответствующих исходников с исходным кодом
55 используемых Go-модулей, лицензиями, рецептом сборки и служебными файлами пакета.
Для автономной сборки ядра установите Go 1.26.8 и выполните `sh BUILD.sh` из архива.
Для сборки пакетов с apk-tools v3:

```sh
python3 scripts/build-openwrt-mips-core.py \
  --binary sing-box-tiny-mipsle --support packaging/stock-support \
  --apk /path/to/apk --output packages
```

Автономная повторная сборка дала тот же SHA-256 бинарника:
`f32f26ef9171684ea10dc1b69b15fc23674af7884fbc210477239bde0db971e0`.
На тестовом SmartBox TURBO+ (MT7621, OpenWrt 25.12.6) пройдены шесть последовательных
запусков с положительными номерами таблиц, без повторного появления loopback в `main`,
и ещё три запуска с тремя активными IPv4-интерфейсами. Все шесть проверок диагностики,
включая DNS и HTTPS через выбранное подключение, завершились успешно.
Сохранённый профиль при проверке совпал с резервной копией. Это не замена проверке
на конкретном ASUS, находящемся в другой сети.
