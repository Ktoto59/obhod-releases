# Обход для OpenWrt — первая версия 0.1.1

Пакеты `obhod` и `luci-app-obhod` добавляют управление через **LuCI → Службы → Обход**.
Готовых туннелей, ключей и URL подписок в пакете нет. После установки служба выключена.

## Совместимость

- OpenWrt 24.10 с opkg: пакеты `.ipk`.
- OpenWrt 25.12 с apk: пакеты формата APK v3 `.apk`.
- Служба и LuCI не содержат машинного кода: один набор `all`/`noarch` подходит
  для Xiaomi AX3000T (MediaTek/Filogic) и Beeline SmartBox TURBO+ (MT7621).
- Полный sing-box **1.12 или новее** устанавливается отдельно из репозитория
  вашей прошивки. Пакетный менеджер выбирает ядро и модули под архитектуру и ядро Linux роутера.
- Требуются firewall4/nftables, TUN и свободное место для sing-box. Поддержка
  не распространяется на заводскую прошивку роутера.

Проверки схемы конфигурации и браузерной логики не заменяют проверку на физическом
роутере. Первая версия требует проверки маршрута LAN, DNS и восстановления после
перезапуска на конкретной прошивке. Производительность на AX3000T и SmartBox TURBO+
ещё не измерена.

## Установка

Онлайн-установщик (интерактивный выбор списков):

```sh
sh <(wget -O - https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh)
```

Переносимый вариант, если оболочка не поддерживает `<(...)`:

```sh
wget -O /tmp/obhod-install.sh https://raw.githubusercontent.com/Ktoto59/obhod-releases/main/openwrt/install.sh && sh /tmp/obhod-install.sh
```

Публичная копия скрипта содержит точную ссылку на комплект версии 0.1.1 и его
SHA-256. Перед распаковкой проверяется архив, затем все файлы внутри него.
Номер версии не запрашивается через `latest`, сертификаты HTTPS не отключаются.

Установщик проверяет общий и доступный объём ОЗУ, накопитель `/overlay` (либо `/`)
и `/tmp`. Минимум: устройство с 128 МБ ОЗУ (112 МБ после резерва ядра), 48 МБ
доступной памяти и 16 МБ в `/tmp`. После обновления индексов выполняется расчёт
недостающих зависимостей по APK solver/opkg dry-run. На накопителе оставляется
запас 8 МБ, в оперативной памяти — запас 32 МБ сверх загрузок и временных файлов.
Используется размер пакетов после распаковки, без предположений о сжатии flash.
Это консервативная оценка установки, а не гарантия производительности под нагрузкой.

Меню предлагает рекомендуемые списки, минимальный набор, выбор по номерам или
установку без готовых списков. Рекомендуемый набор: `russia_inside`, `discord`,
`meta`, `telegram`, `google_ai`. Несовместимые региональные наборы не допускаются.
Выбор сохраняется в `/etc/obhod/defaults.json` и появляется в LuCI после установки.
Существующий профиль с подключениями и списками не перезаписывается.

Для автоматизации и диагностики:

```sh
sh /tmp/obhod-install.sh --yes --check-only
sh /tmp/obhod-install.sh --yes
sh /tmp/obhod-install.sh --presets discord,telegram,youtube
sh /tmp/obhod-install.sh --presets none
```

`--check-only` не устанавливает пакеты и не записывает настройки; индексы
пакетного менеджера обновляются в `/tmp`. Недостаток памяти или неизвестные
размеры зависимостей останавливают установку.

Можно также установить комплект без загрузки через скрипт:

Скопируйте архив `obhod-openwrt-0.1.1.tar.gz` на роутер в `/tmp` и выполните:

```sh
mkdir -p /tmp/obhod-install
tar -xzf /tmp/obhod-openwrt-0.1.1.tar.gz -C /tmp/obhod-install
sh /tmp/obhod-install/install.sh
```

Установщик проверяет OpenWrt, контрольные суммы комплекта и наличие пакетного
менеджера. Если доступен настроенный apk, использует `.apk`; иначе opkg и `.ipk`.
Зависимости устанавливаются с обычной проверкой подписей репозитория. Локальные
пакеты этой сборки не подписаны; `--allow-untrusted` применяется только к ним с
`--no-network`. Постоянные настройки доверия и репозитории не изменяются.

После установки войдите в LuCI заново: для регистрации API и прав доступа
перезапускается rpcd. Импортируйте URL V2Ray-подписки, список
ссылок/Base64, одну ссылку или текст WireGuard `.conf`. Поддерживаются VLESS/Reality,
Shadowsocks, Trojan, Hysteria2, TUIC, AnyTLS, SOCKS5, HTTP(S) и WireGuard при наличии
соответствующих возможностей в sing-box. AmneziaWG и VMess пока не поддерживаются.

Выберите основной сервер либо минимум два сервера для автоматической группы.
Добавьте сайты, подсети или готовые наборы. Укажите LAN-устройство Linux
(обычно `br-lan`), затем нажмите **Сохранить и включить**. Имена WAN-устройств
добавлять не нужно. URL подписки используется однократно и не сохраняется;
для получения новых серверов повторите импорт.
Размер загружаемой подписки на роутере ограничен 128 КБ; локальный профиль — 192 КБ.
Ограничения учитывают размер сообщений RPC и память роутера; при превышении
профиль не записывается и действующие настройки сохраняются.

## DNS и остановка

При автоматическом управлении DNS сначала сохраняются upstream-серверы и
`noresolv` одного экземпляра dnsmasq в `/etc/obhod/dns-backup.json`. После запуска
DNS-слушателя dnsmasq направляет внешние запросы на `127.0.0.1#1053`. Локальные
имена и DHCP остаются у dnsmasq. При остановке или завершении процесса прежние
настройки возвращаются. Если настройки DNS изменены другой программой, Обход
оставляет резервную копию и не перезаписывает чужие изменения.

Для нескольких экземпляров dnsmasq используйте ручной режим DNS и настройте
нужные экземпляры на upstream `127.0.0.1#1053`. Другие менеджеры прозрачного
прокси нужно остановить до запуска Обхода. Правила приложений Windows на роутере
не используются; текстовые внешние списки `.txt`/`.lst` пока не поддерживаются.

```sh
/etc/init.d/obhod stop
/usr/libexec/obhod/dns restore
logread -e obhod
```

Настройки и ключи хранятся в `/etc/obhod/settings.json`, доступ только root
(каталог 0700, файл 0600). DPAPI Windows на роутере отсутствует: защищайте SSH,
LuCI и резервные копии прошивки. Пакеты не включают удалённый доступ и не открывают
API управления на WAN. При остановке ядра системного kill switch нет.

## Сборка

Исходники пакетов: `openwrt/obhod` и `openwrt/luci-app-obhod`. Парсеры подключений
и генератор общие с Windows-версией; браузерный модуль собирается из исходников:

```sh
node scripts/build-openwrt-core.js
python3 scripts/build-openwrt-packages.py --apk /path/to/apk --output release/openwrt
```

Проверки разработки:

```sh
npm test
npm run test:openwrt:ui
npm run openwrt:fixture
python3 scripts/test-openwrt-system.py
```

Последняя команда запускается от root в отдельной Linux-среде. Она создаёт
тестовый rootfs в `/tmp/obhod-openwrt-lab`, проверяет установку APK и IPK настоящими
пакетными менеджерами, транзакции UCI/DNS и откат RPC. Для проверки установки
зависимости заменяются тестовым пакетом; службы и сеть физического роутера не
затрагиваются. Для проверки ошибок запуска используется управляемая заглушка ядра.
Полная схема конфигурации отдельно проверяется настоящим Linux sing-box 1.12.22.

Для создания APK нужен Linux и apk-tools 3 с командой `mkpkg`. Для этой сборки
использован официальный `apk-tools-static 3.0.8-r0` Alpine Linux; инструмент
сборки и sing-box в распространяемый комплект не включаются. SHA-256 архива
инструмента: `673f1bfb22136fc42ca035321cf731a4ad0452c000928666cb39a138f0c277bf`.
Пакеты можно также включить в SDK с установленным feed LuCI; Makefile находятся
рядом с исходниками. Собственный код распространяется по Apache-2.0.

Документация первоисточников: [TUN/auto_redirect sing-box](https://sing-box.sagernet.org/configuration/inbound/tun/),
[APK mkpkg](https://gitlab.alpinelinux.org/alpine/apk-tools/-/blob/v3.0.8/doc/apk-mkpkg.8.scd),
[пакет sing-box OpenWrt 24.10](https://github.com/openwrt/packages/blob/openwrt-24.10/net/sing-box/Makefile).
